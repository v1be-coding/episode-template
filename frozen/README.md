# Frozen tests

Tests written in the Spec phase, before a run starts. CI takes this folder from the PR's base commit, so a run's edits here have no effect, and changing it needs code owner review. See [ADR-0013](https://github.com/v1be-coding/series/blob/main/docs/adr/0013-runs-land-through-auto-merge-and-frozen-tests.md).
